01 / TEAM PROJECT IN DEVELOPMENT

SOFTWARE FOR EDUCATION

SIGE IFCE.

The project SIGE IFCE is a web platform designed to centralize the publication, organization and management of academic and scientific events. Events can contain individual activities such as talks, workshops and short courses, each with its own registration process.

Planned features Event publishing, activity and capacity management, activity-specific registration, attendance tracking, and certificates per activity subject to at least 75% attendance. Access privileges are separated for administrators, organizers, teachers and students.

My contribution Back-end development with Node.js, TypeScript and NestJS: JWT authentication, role-based access control (RBAC), event and activity management APIs, PostgreSQL and Prisma integration, version control and team testing.

TypeScriptNestJSPostgreSQLPrismaAPI REST
Explore technical details

Modular API architecture covering authentication, business rules and data persistence.

  • Draft, published, closed and canceled event states.
  • Event activities with their own capacity and dates.
  • Role permissions and organizer-specific access using JWT and RBAC.
  • Registrations, attendance and certificates belong to the planned scope.

My contribution Study of the models, documentation and workflow prototyping.

Explore the adaptive workflow

The proposal combines Elo-based ability estimation with retention prediction using Half-life Regression (HLR).

  • Answers update performance estimates.
  • Response history informs retention estimates.
  • The system chooses topics and questions for the next review.

Verates.

An application designed to support fake-news identification and combat misinformation. The public version demonstrates the verification flow with a simulated confidence score.

Planned AI techniques Natural Language Processing (NLP) for text analysis and automated news reliability classification. These techniques are not yet implemented in the public repository.

Implemented front end React Native (React), Expo and TypeScript. The prototype shows confidence levels using a demonstration score.
